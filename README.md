# DevForge

The Unified Developer Ecosystem where developers learn, build, share, collaborate, and grow.

## Project Structure (V1)
This project is built using a Modular Monolith architecture powered by npm workspaces and Turborepo.

- **Frontend:** Next.js 15, TailwindCSS, Shadcn UI
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL (Neon) with Prisma ORM
- **Storage:** Azure Blob Storage
